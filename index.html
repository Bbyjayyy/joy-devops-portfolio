PROJECT 01
BASH SCRIPTING93% assignment score

Linux Server Health Monitoring Script

Problem: Repeating multiple Linux commands to inspect a server is time-consuming and produces scattered output.

What I did: Created and ran a Bash script that organises server information and checks disk, memory, CPU, uptime, selected processes and remote connectivity. Used pipes, grep, awk, loops, conditions and basic error handling.

What I learned: How to combine Linux commands into a repeatable report and use Bash logic to automate routine checks.

AWS CLOUD FUNDAMENTALSArchitecture exercise

AWS Services Architecture Exercise

Problem: A sample web application needed suitable AWS services for compute, networking, storage, access control, monitoring, logging and encryption.

What I did: Mapped the requirements to AWS services including EC2, VPC, EBS, S3, IAM, KMS, CloudWatch and CloudTrail, and considered how they fit together in a conceptual architecture.

What I learned: How to select cloud services based on application needs and understand their roles within an architecture.

Conceptual design assignment — not a production deployment.
